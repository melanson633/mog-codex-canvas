# CLAUDE.md

Guidance for this repo lives in [`AGENTS.md`](AGENTS.md) — setup, the check
commands, the invariants that are enforced rather than suggested, and where
the durable knowledge is kept. Read it before changing anything.

It is kept in one file on purpose. Two copies of the same guidance drift
silently, which is the exact failure mode [`docs/solutions/`](docs/solutions/)
exists to prevent.
